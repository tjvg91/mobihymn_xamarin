# Shot list — device capture

Record on a clean iPhone (or Android) frame: status bar clear, no notifications. Prefer real MAUI or PWA build. Light reader theme + one dark theme for contrast.

Capture **longer than the beat** (2–3s pad on each side) so the editor can trim to the locked table in `README.md`.

---

## Pass A — 30s primary (record in order)

### A1 · Brand (need ≥4s)
- [ ] Cold open splash / yellow M on charcoal
- [ ] Hold brand mark steady 2s
- [ ] Soft dissolve toward number-entry screen (do not linger on login)

### A2 · Grid find (need ≥6s)
- [ ] Number entry in **grid** mode
- [ ] Tap hundreds column → tens → ones (familiar number, e.g. 77 or 100)
- [ ] Cut / transition to reader with hymn title + first line visible

### A3 · Voice (need ≥6s)
- [ ] Switch to **voice** number entry
- [ ] Mic listening pulse on screen
- [ ] Say a clear number (e.g. “seventy-seven”)
- [ ] Hymn opens on reader

### A4 · Reader (need ≥6s)
- [ ] Scroll lyrics smoothly
- [ ] Pinch to enlarge / shrink text once
- [ ] Tap to hide chrome (immersive)
- [ ] Quick theme flash: white → sepia **or** dark (1–2 themes only)

### A5 · Audio (need ≥6s)
- [ ] Reader with play bar visible
- [ ] Tap play (yellow control)
- [ ] Scrub seek once; lyrics stay in frame

### A6 · Bookmarks (need ≥6s)
- [ ] Tap heart / bookmark
- [ ] Pick or create group labeled **Sunday** or **Favorites**
- [ ] Toast / confirmation visible

### A7 · Selah (need ≥6s)
- [ ] Open Selah / agent
- [ ] Short prompt on screen: `songs about grace`
- [ ] Suggestion cards appear
- [ ] Tap a suggestion → reader opens

### A8 · Community + end (need ≥5s)
- [ ] Brief groups/board peek (invite code **or** shared setlist — 1–2s max)
- [ ] Hold for end card cutaway (`preview/end-card.png`)
